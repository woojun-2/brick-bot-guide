# BRICK BOT Guide

BRICK BOT은 여러 쇼핑몰 계정을 미리 준비하고, 상품 작업을 계정별로 시작·중지·재시도할 수 있는 Windows용 로컬 컨트롤 센터입니다.

{% hint style="info" %}
처음이라면 **설치 → Discord 인증 → 계정 등록 → 로그인 준비 → 작업 생성** 순서로 읽으세요.
{% endhint %}

## 가장 중요한 사용 순서

1. **Accounts**에서 사용할 사이트의 계정을 등록합니다.
2. 해당 사이트의 **로그인 준비**를 실행합니다.
3. 필요한 CAPTCHA나 추가 확인을 직접 완료합니다.
4. **Tasks**에서 상품·옵션·수량·예약 시각을 입력합니다.
5. 결제 화면에서 상품, 옵션, 수량과 금액을 확인하고 직접 결제를 마칩니다.

{% hint style="warning" %}
CAPTCHA, 대기열, 결제 비밀번호와 최종 결제 승인은 우회하거나 자동 처리하지 않습니다.
{% endhint %}
