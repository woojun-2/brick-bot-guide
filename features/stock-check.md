# Stock Check

Stock Check는 URL만 입력해 사이트를 자동 감지하고 옵션별 최대 주문 가능 수량을 확인합니다.

## 사용 방법

1. 상단 **Stock Check**를 엽니다.
2. 상품 전체 URL을 붙여넣습니다.
3. **SCAN STOCK**을 누릅니다.
4. 옵션, 상태, 수량과 Option ID를 확인합니다.

## 지원 사이트

- Musinsa
- Kasina
- Hoopcity
- 29CM
- Gentle Monster

## 수량의 의미

표시되는 숫자는 단순한 `구매 가능` 표시가 아니라, 사이트가 허용하는 범위에서 해당 옵션을 몇 개까지 주문할 수 있는지 검증한 결과입니다.

{% hint style="info" %}
사이트가 정확한 재고 수량을 공개하지 않거나 회원별 구매 제한을 적용하면 실제 창고 재고와 다를 수 있습니다.
{% endhint %}

## 발매 전 상품

옵션 데이터가 미리 공개된 상품은 발매 전에도 확인할 수 있습니다. 옵션이 아직 공개되지 않았다면 발매 후 다시 조회해야 합니다.
