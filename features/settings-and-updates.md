# Settings & Updates

## Discord Success Webhook

결제 완료가 자동 확인되면 사이트, 상품, 옵션·사이즈, 수량과 완료 시간을 Discord로 전송합니다.

1. Discord 채널 설정에서 Webhook을 만듭니다.
2. Webhook URL을 복사합니다.
3. **Settings → Discord Success Webhook**에 저장합니다.
4. 테스트 전송으로 연결 상태를 확인합니다.

{% hint style="warning" %}
Webhook URL은 채널에 메시지를 보낼 수 있는 비밀 주소입니다. 화면 공유나 로그에 노출하지 마세요.
{% endhint %}

## CAPTCHA Handling

API 키 입력란은 키를 로컬에 암호화 저장하고 연결 상태와 잔액을 확인하는 용도입니다. 실제 사이트의 CAPTCHA는 사용자가 직접 완료합니다.

## Automatic Updates

1. **Settings → Automatic Updates**를 확인합니다.
2. **업데이트 확인**을 누릅니다.
3. 새 버전 다운로드가 끝나면 **업데이트 적용**을 누릅니다.
4. 프로그램이 다시 열릴 때 버전을 확인합니다.

계정, 브라우저 로그인, 작업과 설정은 업데이트 파일과 분리되어 유지됩니다.
