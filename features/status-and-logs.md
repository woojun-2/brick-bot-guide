# Status & Logs

## 작업 상태

| 상태 | 의미 |
|---|---|
| 대기 | 아직 시작하지 않음 |
| 준비 중 | 브라우저·로그인 상태 확인 중 |
| 예약 대기 | 로그인 완료 후 시작 시각 대기 |
| 모니터링 중 | 상품·옵션·예약 오픈 확인 중 |
| 실행 중 | 옵션 선택 또는 주문서 생성 중 |
| 대기열 | 같은 세션으로 입장 순서 대기 |
| 결제 대기 | 사용자 인증 또는 결제 필요 |
| 완료 | 주문 완료 확인됨 |
| 실패 | 오류 발생, Log 확인 필요 |
| 중지됨 | 사용자가 작업을 중지함 |

## 제어 버튼

| 버튼 | 기능 |
|---|---|
| 상세 | 계정별 상태 펼치기 |
| Log | 단계별 시간과 오류 원문 보기 |
| 수정 | 중지된 작업 설정 변경 |
| 시작 | 작업 실행 |
| 중지 | 실행 중인 작업 중지 |
| 재시도 | 실패·중지된 계정 하나만 다시 실행 |
| 삭제 | 작업 삭제 |

## 오류를 전달하는 방법

1. 작업의 **Log**를 누릅니다.
2. 마지막 상태와 실패 직전 단계를 확인합니다.
3. **로그 복사**를 누릅니다.
4. 상품 URL, 실행 시각과 함께 전달합니다.

로그에는 각 단계의 경과 시간이 초 단위로 표시됩니다.
