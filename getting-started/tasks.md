# Tasks

## 새 작업 만들기

1. **Tasks → 새 작업**을 누릅니다.
2. 사이트를 선택합니다.
3. 상품 번호 또는 전체 URL을 입력합니다.
4. 판매 중 상품이면 **상품 조회**로 옵션을 확인합니다.
5. 옵션·사이즈와 수량을 입력합니다.
6. 즉시 실행하거나 예약 시각을 지정합니다.
7. 사용할 계정을 선택합니다.
8. **작업 만들기**를 누릅니다.

미출시 상품은 조회 결과가 없어도 알고 있는 상품 번호와 옵션을 직접 입력해 예약 작업을 만들 수 있습니다.

## 실행 모드

| 모드 | 설명 |
|---|---|
| 웹 모드 | 사이트 화면을 따라 주문서까지 진행 |
| Direct API · 빠른 주문 | 사이트의 공식 상품·주문 흐름을 사용해 주문서 진입 시간을 단축 |

사이트에 따라 사용할 수 있는 모드가 자동으로 제한됩니다.

## 예약 작업

예약 작업도 미리 **시작**해야 합니다.

1. 시작 즉시 계정 준비 상태를 확인합니다.
2. 준비가 끝나면 예약 시각까지 대기합니다.
3. 예약 시각부터 상품 또는 옵션을 일정 간격으로 다시 확인합니다.
4. 상품이 열리면 주문 단계로 진행합니다.

{% hint style="warning" %}
예약 시각이 곧 판매 시각이라는 뜻은 아닙니다. 사이트가 늦게 열리거나 대기열이 나타날 수 있으며, 같은 세션을 유지한 채 상태를 확인합니다.
{% endhint %}

## 작업 수정

작업을 중지한 뒤 **수정**을 누르면 상품 번호, 옵션·사이즈, 수량, 예약 시각과 계정을 바꿀 수 있습니다.
