# Discord Login

BRICK BOT은 허용된 Discord 서버 멤버인지 확인한 뒤 실행됩니다.

## 로그인 방법

1. 시작 화면에서 **Discord로 로그인**을 누릅니다.
2. 열린 Discord 인증 창에서 사용할 계정을 확인합니다.
3. 요청 권한을 확인하고 승인합니다.
4. 인증이 끝나면 BRICK BOT으로 돌아옵니다.

상단에는 현재 라이선스의 남은 기간이 표시될 수 있습니다. 기간이 만료되거나 계정이 정지되면 작업 시작이 제한됩니다.

## 인증되지 않을 때

- 올바른 Discord 계정으로 로그인했는지 확인합니다.
- 해당 계정이 지정된 Discord 서버에 가입되어 있는지 확인합니다.
- 인증 창을 닫았다면 **Discord 세션 초기화 후 로그인**을 다시 실행합니다.
- 기간 만료 또는 정지 메시지는 관리자에게 문의합니다.

{% hint style="warning" %}
다른 사람의 Discord 계정을 사용하거나 인증 세션을 공유하지 마세요.
{% endhint %}
