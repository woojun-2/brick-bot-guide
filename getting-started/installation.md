# Installation

## Windows 설치

1. 최신 `BRICK-BOT-Setup.exe`를 실행합니다.
2. Windows 확인 창이 나오면 파일명을 확인한 뒤 계속합니다.
3. 설치가 끝나면 바탕화면의 **BRICK BOT** 아이콘을 실행합니다.
4. 첫 화면에서 Discord 인증을 완료합니다.

별도의 Node.js, npm 또는 Chromium 설치는 필요하지 않습니다. 공식 설치본에는 실행에 필요한 구성 요소가 포함됩니다.

## 업데이트

BRICK BOT은 실행할 때 새 버전을 확인합니다. 업데이트가 있으면 백그라운드에서 내려받은 뒤 **Settings → Automatic Updates**에서 적용할 수 있습니다.

{% hint style="info" %}
업데이트 후에도 계정, 브라우저 로그인, 작업과 설정은 사용자 데이터 폴더에 유지됩니다.
{% endhint %}

## 실행되지 않을 때

- BRICK BOT을 완전히 종료한 뒤 다시 실행합니다.
- 보안 프로그램이 설치파일 또는 내장 브라우저를 격리했는지 확인합니다.
- 기존 파일을 직접 덮어쓰기보다 최신 설치파일로 재설치합니다.
- 계속 실패하면 작업의 **Log** 또는 실행 오류 화면을 복사해 전달합니다.
