# Accounts

Accounts에서는 사이트별 계정과 독립 브라우저 프로필을 관리합니다.

## 계정 추가

1. **Accounts → 계정 추가**를 누릅니다.
2. 사이트를 선택합니다.
3. 한 줄에 하나씩 `ID:PW` 형식으로 입력합니다.
4. **계정 저장**을 누릅니다.

```text
example_id:password
second_id:password
```

- 같은 사이트에 같은 ID를 다시 저장하면 비밀번호가 갱신됩니다.
- 비밀번호는 목록에 다시 표시되지 않습니다.
- 계정 번호는 사이트마다 `01`부터 시작합니다.

## 로그인 준비

사이트 카드를 선택한 뒤 **로그인 준비**를 누릅니다. 여러 계정은 PC 부하를 줄이기 위해 순차 준비될 수 있지만, 준비가 끝난 계정은 Tasks 시작 시 동시에 상품 단계로 이동합니다.

| 버튼 | 기능 |
|---|---|
| 열기 | 해당 계정 브라우저 실행 |
| 준비 | 로그인과 사이트 준비 실행 |
| 보기 | 숨겨진 브라우저 화면 표시 |
| 숨기기 | 브라우저를 백그라운드로 숨김 |
| 닫기 | 해당 계정 브라우저 종료 |

## Musinsa CAPTCHA

Musinsa에서 CAPTCHA가 나타나면 다음 순서로 처리합니다.

1. 해당 계정의 **보기**를 누릅니다.
2. CAPTCHA를 직접 완료합니다.
3. 미리 입력된 ID와 비밀번호를 확인합니다.
4. 로그인 버튼을 직접 누릅니다.
5. 로그인 완료 후 창을 다시 숨깁니다.

{% hint style="info" %}
CAPTCHA를 완료한 뒤 로그인 화면으로 돌아오면 저장된 계정 정보가 다시 채워집니다.
{% endhint %}
