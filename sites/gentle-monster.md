# Gentle Monster

## 상품 입력

상품 URL 또는 상품 식별값을 입력합니다. 전체 URL 사용을 권장합니다.

```text
https://www.gentlemonster.com/kr/ko/item/S11500921/pradagentlemonster101
```

안경 상품의 기본 사이즈는 `R`로 처리됩니다.

## 실행 방식

- Direct API · 빠른 주문
- 공식 판매 상태 모니터링
- 대기열 발생 시 같은 세션 유지
- 상태 영역에 가능한 경우 대기 인원 표시

## 결제

네이버페이 화면을 메인 Google Chrome으로 전달합니다. 로그인 버튼, 추가 인증과 최종 결제는 직접 확인합니다.
