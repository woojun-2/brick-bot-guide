# Worksout

## 상품 입력

상품 번호 또는 전체 URL을 입력합니다.

```text
339800
```

```text
https://www.worksout.co.kr/products/339800
```

## 1개 구매

- 사이즈 1만 입력합니다.
- `2개 구매`를 끕니다.
- 장바구니를 비우지 않고 상품의 **구매하기**로 바로 이동합니다.

## 2개 구매

- `2개 구매`를 켭니다.
- 사이즈 1과 사이즈 2를 입력합니다.
- 시작 전에 장바구니를 정리합니다.
- 두 옵션을 담고 전체 선택 후 주문서로 이동합니다.

## 결제

네이버페이 화면은 로그인된 메인 Google Chrome으로 전달됩니다. 네이버 로그인, 결제 비밀번호와 최종 결제는 직접 진행합니다.
