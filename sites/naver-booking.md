# Naver Booking

## 상품 입력

URL의 `businessId,itemId`를 쉼표로 입력합니다.

```text
259322,3179379
```

BRICK BOT이 아래 형식의 예약 URL로 변환합니다.

```text
https://m.booking.naver.com/booking/10/bizes/259322/items/3179379
```

## 예약 정보

- 예약 날짜
- 예약 시간
- 수량
- 작업 시작 시각

예약 날짜와 시간은 입력창의 선택기를 사용할 수 있습니다.

## 지원하는 시간 화면

- 연속된 막대에서 시간을 고르는 화면
- 30분 단위 버튼으로 시간을 고르는 화면

## 실행 흐름

1. 예약 오픈을 확인합니다.
2. 날짜를 선택합니다.
3. 원하는 시간을 선택합니다.
4. **다음**으로 이동합니다.
5. 약관을 확인하고 동의합니다.
6. **동의하고 예약하기**를 누릅니다.

두 번째 페이지에서 예상하지 못한 항목이 나타나면 제한된 횟수만 재시도한 뒤 브라우저를 표시해 사용자가 직접 이어서 처리합니다.
